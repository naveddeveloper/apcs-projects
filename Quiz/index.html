About NavedQuiz

NavedQuiz is a comprehensive, client-side frontend web development examination and self-study platform developed by Naved for APCS. It is engineered entirely with HTML5, CSS3, and Vanilla JavaScript, without any external dependencies, frameworks, or libraries.

Core Topics Tested

  • HTML5 Quiz (15 Questions): Document structure, doctype declarations, semantic containers, accessible forms, image attributes, links, tables, and WAI-ARIA fundamentals.
  • CSS3 Quiz (15 Questions): Selectors, inheritance, specificity calculation, the standard and border-box models, Flexbox axis alignment, CSS Grid tracks, positioning contexts, and responsive media queries.
  • JavaScript Quiz (15 Questions): Primitive types, let vs const vs var scoping, arrow and standard functions, condition branches, array higher-order methods (map, filter, reduce), DOM selectors, event listeners, and asynchronous execution principles.

Design & Technical Highlights

  • Fully Responsive Layout: Seamless adaptation across desktop, tablet, and mobile viewports with fluid CSS Grid and Flexbox structures.
  • Robust State Management: Reusable quiz engine with real-time score updates, per-question progress tracking, and strict submission locks.
  • In-Depth Review Mode: Examine every answered and unanswered question post-completion with correct answers and explanations clearly highlighted.
  • Local Performance Tracking: Safe browser-level localStorage persistence computing overall averages, best scores, and category breakdowns.

Frontend Quick Reference

HTML5 Semantic Elements

Use structural tags to describe content purpose: <header>, <nav>, <main>, <article>, <section>, <aside>, and <footer>.

CSS Specificity Hierarchy

Inline styles (1000) > ID selectors (100) > Classes, pseudo-classes, attributes (10) > Elements, pseudo-elements (1).

CSS Box Model

box-sizing: border-box ensures width and height include content, padding, and border.

JavaScript Variable Scoping

const and let are block-scoped {} with temporal dead zone; var is function-scoped.

Key Array Methods

map() transforms elements into a new array. filter() retains elements matching condition. reduce() accumulates values into a single result.
